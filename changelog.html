Changelog

Web Scanner updates arrive through the Chrome Web Store.

1.3.0

October 2026

  • A new interface: a security report with a grade, sorted into what to fix first and smaller risks, in plain words.
  • Broken links list every page they are on with the link text, and redirects show their full chain.
  • Pro: scan a sitemap.xml or a list of URLs, with no URL limit per scan.
  • Pro: security check of every crawled page, showing which pages share each issue.
  • Pro: client report with your name or logo, send to developer, CSV and JSON export.
  • Pro: history with a comparison after each rescan.
  • Popup, side panel and full-tab layouts, dark and light themes, English and Turkish.

1.2.0

October 2026

  • Pro Lifetime license through Lemon Squeezy.
  • Passive security checks with fix snippets for common servers.
  • Link scan with the page each broken link was found on.
